# 구급대원 증상별 임상추론 참고서 v26

## 핵심
- iPhone / Android 모두 지원하는 휴대폰 수첩형 PWA
- PC에서는 기존 화면, 휴대폰에서는 세로 수첩 화면
- 좌우 스와이프, 목차, 홈 화면 추가, 오프라인 캐시 지원
- **임상 내용은 `data.js` 하나로 분리**했습니다.

## GitHub에 올리는 방법
1. ZIP 압축을 풉니다.
2. GitHub 저장소의 `main` 브랜치 루트에 **파일 전체**를 올립니다.
3. GitHub Pages를 `main / root`로 설정합니다.
4. 생성된 주소를 iPhone Safari 또는 Android Chrome에서 엽니다.
5. 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 내용 업데이트 방법
나중에 임상 내용을 수정할 때는 `data.js`만 수정하면 됩니다.
- 증상 추가/삭제
- 위험신호 수정
- 임상추론 가지 수정
- 확인 항목 수정
- 현장 기억 포인트 수정

GitHub에서 `data.js`를 클릭 → 연필(Edit) → 수정 → Commit changes 하면 됩니다.
화면 프로그램(`index.html`)을 건드릴 필요가 없습니다.

## 주의
GitHub Pages에서 이미 설치된 PWA의 이전 내용이 보이면 브라우저를 한 번 새로고침하거나 앱을 다시 열어 캐시가 갱신되도록 합니다.
